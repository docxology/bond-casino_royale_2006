# Testing Philosophy

The LE CHIFFRE test suite follows four hard rules: **real data**, **zero
mocks**, **determinism**, and **≥90% line-and-branch coverage on `src/`**.

## Zero mocks

No `unittest.mock`, `MagicMock`, `@patch`, or `create_autospec`. Deterministic
test data is generated by the domain modules themselves (seeded synthetic
scenes in `laundering_detect.synthetic_flow`, `poison_detect.synthetic_panels`,
and fixed hand-built graphs in the routing tests). Cross-checks use *real*
alternative algorithms (e.g. `brute_force_path` verified against Dijkstra).

## Determinism

- Fixed, documented seeds (`scenarios.SEED = 17`).
- Every RNG is a caller-supplied `random.Random(seed)`; the global RNG is never
  used or seeded by tests.
- Manuscript variable tests pass an explicit `now=` timestamp override so
  `GENERATION_TIMESTAMP` is deterministic.

## Coverage command

```bash
uv run pytest tests/ --cov=src --cov-fail-under=90 -q
```

`pyproject.toml` sets `branch = true` and `fail_under = 90`; coverage is
counted on `src/casino_royale_2006` only. The live test count and achieved
coverage are recorded in `docs/_generated/COUNTS.md` (regenerated, never
hand-edited).

## Test-file inventory

| File | Covers |
|---|---|
| `test_poker_engine.py` | hand eval vectors, exact turn/river equity, Monte-Carlo, pot odds/EV, opponent model, ranges |
| `test_laundering_detect.py` | struct/round-trip/velocity/parking primitives, `detect` on seeded synthetic scenes |
| `test_urban_routes.py` | feasibility, Dijkstra vs. brute force, tie-break determinism, unreachable |
| `test_poison_detect.py` | grade thresholds, posterior, source identification, antidote plan |
| `test_mission.py` | protocol conformance, `run_mission` flow, gadget registration, discovery |
| `test_manuscript_variables.py` | config load, token map, live `{{TOKEN}}` cross-reference, resolve tree |
| `test_scripts_smoke.py` | subprocess runs of each phase CLI + manuscript/variables script |

## What counts as a passing test

Real assertions on real outputs: exact known hand-rank vectors, equity bounds
against published AA-vs-KK preflop (~81.9%), determinism (two runs identical),
error branches (`ValueError` / `KeyError`), and presence of generated artifacts.
